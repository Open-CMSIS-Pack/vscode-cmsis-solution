# Principles

1. Search for an existing implementation before adding code.
2. Reuse or extend the owning abstraction when responsibilities match.
3. Keep responsibilities cohesive and dependencies explicit.
4. Use interfaces at replaceable or external boundaries.
5. Keep implementation details behind their owning interface.
6. Do not add abstractions for a single speculative use.
7. Keep changes focused; do not refactor unrelated code.
