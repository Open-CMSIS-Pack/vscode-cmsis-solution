# Plan

1. Read and follow the [local overlay instructions](../../instructions/local-overlays.md).
2. Read and follow the [development principles](../../instructions/principles.md).
3. When planning JSON, YAML, or XML parsing, creation, or updates, consult the [structured-files skill](../structured-files/SKILL.md) to select the appropriate existing API and identify filesystem or format-preservation constraints.
4. Consult the [architecture](../../references/architecture.md), [structure](../../references/structure.md), and [module map](../../references/modules.md) only as needed.
5. Inspect the smallest code surface needed to resolve assumptions.
6. State assumptions and decisions that affect the implementation.
7. Produce ordered implementation and verification steps without changing code.
