# Extension-owned file formats

This directory contains the machine-readable schemas and companion
documentation for files owned or generated by the CMSIS Solution extension.

| File | Documentation | Schema |
| --- | --- | --- |
| `.vscode/cmsis.json` | [CMSIS workspace settings](cmsis.md) | [cmsis.schema.json](cmsis.schema.json) |
| `.cmsis/tools-environment.yml` | [CMSIS tools environment](tools-environment.md) | [tools-environment.schema.json](tools-environment.schema.json) |

The documentation describes ownership, lifecycle, compatibility, and field
semantics. The JSON Schema files are machine-readable definitions used by
tests and available to consumers for validation.
