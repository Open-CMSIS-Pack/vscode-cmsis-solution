# Agent Guidance

1. Treat `.agents/` as the canonical source of repository guidance.
2. Before planning or changing code, follow the [local overlay instructions](.agents/instructions/local-overlays.md).
3. For planning, investigation, design, or scoping without code changes, follow the [plan skill](.agents/skills/plan/SKILL.md).
4. For implementation, fixes, refactoring, or validation, follow the [change skill](.agents/skills/change/SKILL.md).
5. Local guidance has precedence over public guidance. If local and public guidance conflict, or local files conflict with each other, ask the user which rule to follow before proceeding.
